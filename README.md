# SILVA EDIT

動画・音声ファイルを Chrome のサイドパネルで手早く編集できる拡張機能です。  
トリミング、クロップ、回転/反転、再生速度変更、音声抽出、フレーム保存に対応しています。

## 主な機能

- 長さトリミング（iOS風シークバー / 数値入力 双方向同期）
- 解像度クロップ（8点ハンドル + アスペクト比固定 1:1 / 4:3 / 16:9 / 9:16、Shiftで一時固定）
- 回転（90°単位）・左右反転・上下反転
- 再生速度変更（0.25x〜4x）
- 動画音量調整（0〜200%）
- MP4 書き出し
- MP3 書き出し（高: 320kbps / 中: 192kbps）
- 現在フレーム保存（PNG）
- クロップ後フレーム保存（PNG）
- **一括分割モード**: マーカーで複数クリップに分割し、まとめて MP4 / MP3 / 先頭フレーム を一括書き出し
- UI テーマ切替（ゆるシルバ / キリシルバ）

## 対応フォーマット

### 入力

- 動画: `mp4`, `webm`, `mov`, `ogv`, `mkv`（`video/*`）
- 音声: `mp3`, `wav`, `m4a`, `aac`, `ogg`, `flac`, `opus`（`audio/*`）

### 出力

- 編集動画: `mp4`
- 音声のみ: `mp3`
- フレーム画像: `png`

## インストール（ローカル）

1. `chrome://extensions` を開く
2. 「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
4. ツールバーの SILVA EDIT アイコンをクリックしてサイドパネルを開く

## 使い方

### 通常編集モード

1. 動画/音声をドラッグ&ドロップ（またはクリック選択）
2. 必要に応じて開始・終了時間（シークバー or 数値入力）、クロップ範囲、速度、回転/反転を調整
3. 以下のいずれかを実行
   - `編集動画書き出し`（MP4）
   - `音声のみ保存（MP3）`
   - `現在フレームを保存` / `切り取ったフレームを保存`（PNG）

### 一括分割モード

1. ヘッダの `一括分割` ボタンでモード切替
2. タイムラインをクリックで分割線を追加、または `現在位置で分割` ボタン、もしくは `N秒ごとに自動分割`
3. 分割線をドラッグで微調整、リスト内の数値で精密調整
4. 各クリップ行の `MP4` / `MP3` で個別書き出し、または下部の `分割を一括書き出し` で全クリップを連続出力
5. 対応ブラウザ（Chrome 等）では、保存先フォルダを最初に選ぶダイアログが出ます。フォルダ選択しない場合は通常のダウンロード（複数DL許可プロンプトが出ることがあります）

## 動作方針（プライバシー）

- `ffmpeg-core.wasm` を使ったローカル処理です
- 編集対象ファイルを外部サーバーへアップロードしません
- 権限は `sidePanel` のみ（`manifest.json`）

## 注意点

- 音声ファイル入力時は動画系操作（クロップ、回転/反転、動画書き出し、フレーム保存、一括分割）は無効になります
- 大きなファイルはブラウザメモリ使用量が増え、処理時間も長くなります
- 一括分割の書き出し中はサイドパネルを閉じないでください（処理が中断されます）
- 連続ダウンロード時、Chrome から「複数のファイルをダウンロードしようとしています」プロンプトが出る場合があります。初回に許可してください
- サイトではなく拡張サイドパネル上で完結するツールです

## ファイル構成

- `manifest.json`: 拡張定義（MV3 / サイドパネル）
- `background.js`: アクションクリック時のサイドパネル起動
- `panel.html`: UI レイアウト
- `panel.css`: UI スタイル
- `panel.js`: 編集ロジック（トリム/クロップ/変形/FFmpeg処理）
- `vendor/ffmpeg/`: FFmpeg WASM 関連ファイル
- `images/`: アイコン類

## 開発メモ

- バージョン更新時は `manifest.json` の `version` を更新
- UI 変更時は `panel.html` と `panel.css` をセットで調整
- 書き出しロジックの変更は `panel.js` の FFmpeg 引数を確認
